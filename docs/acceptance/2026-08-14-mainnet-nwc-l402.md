# Mainnet NWC-to-L402 acceptance — 14 August 2026

Status: **PASS**

This record covers one controlled, real-money automated payment through the
released MCP server:

`402-mcp → @forgesworn/nwc-kit → Rizful → Satgate → Phoenixd`

It complements Satgate's earlier human Wallet of Satoshi acceptance. The two
tests use independent payer wallets and exercise different client paths.

## Safety envelope

- A dedicated Rizful test vault held 20 sats before the run.
- Rizful's connection had a wallet-side spending limit and expiry. The vault's
  20-sat balance was the tighter hard loss bound.
- `MAX_AUTO_PAY_SATS=10` capped a single autonomous payment.
- `MAX_SPEND_PER_MINUTE_SATS=10` capped the rolling 60-second spend.
- `FETCH_MAX_RETRIES=0` disabled generic HTTP retries.
- The MCP harness allowed one `autoPay` invocation and no blind payment retry.
- The NWC bearer URI was loaded from a temporary `0600` file into an isolated
  process. The file and isolated encrypted L402 credential store were removed
  after the run.

## Free-tier gate

Satgate deliberately grants 250 free credits per IP per day. The first dry run
therefore returned HTTP 200 without asking the wallet to pay. The safety gate
stopped before `autoPay`, and Rizful still showed 20 sats with no outgoing
transaction.

The remaining allowance for the test IP was then consumed with lightweight GET
requests that passed through the payment middleware but did not invoke the
model. The next dry run returned a fresh HTTP 402 challenge for exactly 10 sats.
Only then was `autoPay` enabled.

## Credential handling

The public record deliberately excludes the BOLT11 invoice, payment hash,
preimage, L402 macaroon, Rizful address and NWC bearer URI. Payer and receiver
records were reconciled without printing those values.

## What this proves

This proves one end-to-end mainnet path in which the released MCP server parsed
a production L402 challenge, enforced both local spend caps, made one automated
NWC payment through an independent wallet provider, verified cryptographic
settlement, stored the resulting credential, retried the request and received
paid inference. The receiver independently accounted for the same 10 sats.

It does not prove every NWC wallet, relay, route, model or payment rail; sustained
availability or throughput; or that a 20-sat test vault is suitable for holding
material funds.
